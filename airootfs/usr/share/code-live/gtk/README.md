# Bundled GTK theme

`/usr/share/themes/catppuccin-mocha-rosewater-standard+default` is copied
unchanged from the source PC's `catppuccin-gtk-theme-mocha` package, version
1.0.3-1. Only the selected standard Rosewater variant is included.

Upstream: https://github.com/catppuccin/gtk

License: GPL-3.0 (package metadata). A copy is included as `COPYING` here.

GTK settings are copied from the source PC's GTK 3/4 `settings.ini` files.
GTK 4 CSS override symlinks from the host are not copied; applications that
ignore theme selection (notably libadwaita) are not forcibly restyled.
